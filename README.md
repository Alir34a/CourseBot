# ربات دوره‌ساز تلگرام

دورهٔ مرحله‌ای داخل تلگرام، بدون پنل وب. هر اپیزود یک رسانه به‌علاوهٔ متن است؛ کاربر شماره‌اش را با دکمه می‌فرستد و بعد از دیدن هر اپیزود، اپیزود بعدی باز می‌شود. ساخت دوره، متن‌ها و رسانه‌ها از داخل خود تلگرام انجام می‌شود.

موضوع دوره مهم نیست؛ با هر تعداد اپیزود کار می‌کند و چند دوره هم‌زمان هم پشتیبانی می‌شود.

## چه کار می‌کند

- ثبت‌نام با شمارهٔ واقعی — فقط از دکمهٔ کانتکت، شمارهٔ تایپی و کانتکت جعلی رد می‌شود
- قفل مرحله‌ای: اپیزود بعدی تا دیدن قبلی باز نمی‌شود و این قفل سمت سرور چک می‌شود
- نوار پیشرفت روی هر اپیزود و درصد پیشرفت جدا برای هر دوره
- رسانه‌های ویدیو، عکس، صوت، ویس، ویدیوی دایره‌ای و فایل؛ متن بلند خودکار چند پیام می‌شود
- پیشنهاد خرید با زمان‌بندی دلخواه (بعد از اپیزود N یا همیشه) و تأیید دستی مدیر
- آمار دیده/کلیک/خرید، قیف و ریزش هر اپیزود، جست‌وجوی کاربران
- پیام تکی یا گروهی با پیش‌نمایش تعداد گیرنده
- ویرایش متن‌های ربات بدون کدنویس — از پنل، یا از دکمهٔ «متن‌های این صفحه» داخل همان صفحه‌ای که داری می‌بینی
- پشتیبان‌گیری و بازیابی دیتابیس

## اجرا

```bat
pip install -r requirements.txt
copy config\.env.example .env
```

سه مقدار را در `.env` پر کن:

| کلید | از کجا |
|---|---|
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) ← `/newbot` |
| `ADMIN_IDS` | [@userinfobot](https://t.me/userinfobot) ← عدد `Id`. چندتا با کاما |
| `OWNER_EMAIL` | ایمیل خودت |

```bat
python -m bot.main
```

بار اول دیتابیس خالی ساخته می‌شود. بعد در تلگرام `/admin` بزن و دوره و اپیزودهایت را بساز.

روی سرور بهتر است با systemd بالا بیاید تا با ری‌استارت خودکار بالا بیاید — راهنمایش در [docs/INSTALL.md](docs/INSTALL.md) است.

## یک نکته دربارهٔ رفتار پیام‌ها

منوها تکرار نمی‌شوند. هر بار که بین منوها می‌گردی همان یک پیام درجا عوض می‌شود و چیزی به گفتگو اضافه نمی‌شود؛ منوی قبلی هم پاک می‌شود.

ولی محتوای اپیزودها دست‌نخورده می‌ماند. تلگرام اجازه نمی‌دهد پیام ویدیو را ویرایش کنی، و ضمناً این‌طور می‌توانی برگردی و اپیزودی را که خواندی دوباره ببینی.

## نکته

`.env` شامل توکن است و باید همان‌جا بماند. اگر زمانی لازم شد جابه‌جایی‌اش کنی، توکن را از BotFather باطل کن و تازه بگیر — چیزی که یک‌بار داخل گیت رفته باشد از تاریخچه پاک نمی‌شود.

# نصب و راه‌اندازی از صفر (فقط ربات — بدون وب‌سرور)

## ۱. پیش‌نیاز
پایتون 3.11+ و اکانت تلگرام.

## ۲. وابستگی‌ها
```bat
pip install -r requirements.txt
```
(فقط python-telegram-bot، dotenv و pytest — هیچ فریم‌ورک وبی نیست.)

## ۳. `.env` (دستی، توسط صاحب پروژه)
```bat
copy config\.env.example .env
notepad .env
```
اجباری: `BOT_TOKEN`، `ADMIN_IDS`، `OWNER_EMAIL`. بقیه اختیاری/پیش‌فرض دارند.
`.env` در `.gitignore` است و هرگز کامیت نمی‌شود.

## ۴. اجرا
```bat
python -m bot.main
```
دیتابیس (`DATABASE_PATH`) + مایگریشن‌ها خودکار ساخته می‌شود. شروع تمیز و خالی است؛ دوره را از `/admin` می‌سازی.
مایگریشن‌ها نسخه‌دارند (`database/migrations/`) و اجرای مجدد امن است.

## ۵. مدیریت (همه داخل تلگرام)
از اکانت مدیر (آیدی داخل `ADMIN_IDS`) دستور `/admin`:
📚 دوره‌ها (ساخت/حذف/فعال)، 📺 اپیزود (متن/رسانه/ویرایش)، 📝 متن‌های ربات،
🎁 پیشنهاد، 💰 تأیید خرید، 📣 پیام، 📊 آمار. جزئیات: `ADMIN_GUIDE.md`.

## ۶. بکاپ/بازیابی
```bat
python -m modules.backup backup
python -m modules.backup restore data\backups\bot-<ts>.db --i-stopped-the-bot
```
بازیابی فقط وقتی ربات **خاموش** است.

## ۷. تست
```bat
python -m pytest tests/ -q -p no:asyncio
```
